# Proyecto Teórico-Práctico: Diseño y Simulación de una Red Inteligente para la Conexión entre dos Laboratorios de UPIITA

## Propósito del Proyecto

Este proyecto tiene como objetivo simular una red inteligente que conecte dos equipos en el laboratorio de UPIITA o en una red externa. El proyecto abordará aspectos de señalización, VoIP, redes inteligentes móviles y las tendencias actuales en telecomunicaciones. La meta es aplicar estándares y principios de telecomunicaciones para la administración y operación de redes de comunicación modernas.

## Objetivos Específicos

1. **Comprender los principios de señalización en redes de telecomunicaciones.**  
   - Estudio y análisis de los protocolos y mensajes utilizados en redes de telecomunicaciones, incluyendo SIP, SS7 y LTE.
  
2. **Implementar un prototipo básico de VoIP para comunicación entre los laboratorios usando una herramienta.**  
   - Configuración de un sistema VoIP utilizando herramientas como Asterisk y clientes SIP para establecer comunicación entre los dos laboratorios.

3. **Diseñar y simular una red inteligente para conectar ambos laboratorios, aplicando estándares como SIP, SS7 o LTE.**  
   - Creación y simulación de una red inteligente que permita la conexión de los laboratorios a través de tecnologías avanzadas y protocolos de señalización.

## Descripción

En este proyecto, se utilizarán diversas herramientas y tecnologías para la creación de una red inteligente que integre diferentes conceptos clave de telecomunicaciones:

- **Señalización en redes de telecomunicaciones:** Estudio del uso de protocolos como SIP (Session Initiation Protocol), SS7 (Signaling System 7) y LTE (Long-Term Evolution) para gestionar las comunicaciones entre los equipos.
  
- **VoIP:** Implementación de un sistema básico de comunicación de voz sobre IP para permitir la comunicación entre los laboratorios de UPIITA.

- **Redes inteligentes:** Diseño de una red que sea capaz de adaptarse a las condiciones cambiantes, usando principios de redes inteligentes y las tecnologías más avanzadas de telecomunicaciones.

## Herramientas y Tecnologías

- **Asterisk**: Software de servidor de comunicaciones utilizado para gestionar la señalización VoIP.
- **SIP (Session Initiation Protocol)**: Protocolo de señalización utilizado para establecer, mantener y finalizar sesiones de comunicación.
- **MicroSIP**: Cliente SIP usado para la configuración y prueba de la comunicación VoIP.
- **Wireshark**: Herramienta de captura y análisis de paquetes para monitorear el tráfico de red.
- **SS7 y LTE**: Protocolos avanzados utilizados en redes móviles y de telecomunicaciones para señalización y comunicación.

## Requisitos

### Software

- Asterisk instalado y configurado en el servidor.
- MicroSIP configurado en los dispositivos cliente.
- Wireshark para monitoreo y análisis de tráfico.

### Hardware

- Computadoras con acceso a la red de UPIITA.
- Conexión de red entre los laboratorios de UPIITA.
